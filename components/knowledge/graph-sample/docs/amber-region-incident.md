# Cluster Amber region and incident

Cluster Amber runs in region Vane-1 and had a power outage on 3 March. A faulty transfer switch in the data hall cut two racks for about twenty minutes. The same date has been mistaken for other incidents in the past, so the review is filed under the region name. Amber's nodes restarted cleanly and the databases recovered without manual repair. The facility provider has since replaced the switch.
