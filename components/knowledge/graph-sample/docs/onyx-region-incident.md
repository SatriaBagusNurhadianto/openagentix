# Cluster Onyx region and incident

Cluster Onyx runs in region Vane-2 and had a network outage on 12 April. A routing change at the provider isolated the region from the internet for roughly half an hour. Internal traffic kept flowing, so only the public endpoints were affected. The review recommended a second uplink, which was approved but not yet installed. Until then the on-call engineer has a checklist for a manual failover.
